# JavaScript Fundamentals

A collection of JavaScript exercises focused on algorithmic problem-solving and DOM manipulation, written in vanilla JavaScript (no frameworks or libraries).

## Structure

```
javascript-fundamentals/
├── algorithms/          # Algorithmic problem-solving exercises
└── dom/                 # DOM manipulation exercises
```

## Algorithms

| Exercise | Description |
|---|---|
| [Trapping Rain Water](./algorithms/trapping-rain-water) | Classic array problem — calculates how much water can be trapped between bars of varying heights (LeetCode Hard). |
| [Mastermind](./algorithms/mastermind) | Code-breaking game logic — compares a guess against a hidden code and returns exact/partial matches, handling duplicate digits correctly. |
| [Tower Cost Optimization](./algorithms/tower-cost-optimization) | Given a set of values and a fixed adjustment, finds the split that minimizes the difference between the resulting maximum and minimum. |
| [Stock Trading](./algorithms/stock-trading) | Single-pass algorithm to determine the optimal buy/sell points in a sequence of prices to maximize profit. |
| [Parking Permutations](./algorithms/parking-permutations) | Generates and evaluates possible arrangements under a set of constraints. |
| [Wave Array](./algorithms/wave-array) | Identifies local peaks in an array of prices and returns the best one based on given criteria. |
| [Blackjack Game](./algorithms/blackjack-game) | Simple card game simulation with score tracking and win/loss logic. |
| [User Management](./algorithms/user-management) | CRUD-style logic for managing a list of users, including sorting and filtering. |

## DOM Manipulation

| Exercise | Description |
|---|---|
| [Image Slider](./dom/image-slider) | Slider with thumbnail navigation, built using vanilla DOM methods (no libraries). |
| [Dynamic Table](./dom/dynamic-table) | Table generated and updated dynamically from JavaScript data, with computed values (e.g. averages). |
| [Dynamic CSS Injection](./dom/dynamic-css-injection) | Creates and styles elements at runtime using `createElement`, `appendChild`, and dynamic class assignment. |
| [Random Cell Fill](./dom/random-cell-fill) | Populates a table with randomly selected, non-repeating cells using a `while` loop. |

## How to Run

Each exercise is self-contained in its own folder. Open the `index.html` file in any modern browser — no build step or dependencies required.
