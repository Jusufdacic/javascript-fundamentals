# Igra 21 (Blackjack)

## Task

Implement a simplified two-player Blackjack (21) game: players are dealt random cards, their totals are tracked, and the game determines a winner based on standard 21 rules (closest to 21 without going over wins; going over busts).

## Approach

Random card values are generated and summed per player. Game logic compares both totals against the 21 limit to determine the outcome (win, loss, bust, or tie), with the UI updating dynamically after each round.
